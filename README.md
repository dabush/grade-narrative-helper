# Grade Narrative Helper

A free tool for teachers who write report card comments. Click through ratings for each student, or for each assignment, and the tool assembles everything into a clean summary per student. Paste that summary into Claude, ChatGPT or another AI chat to draft comments grounded in real data.

**Use it here:** https://dabush.github.io/grade-narrative-helper/

## How it works

1. **Set up:** add your major assignments, the learning milestones students are working toward, and, optionally, the classroom behaviors you look for. Starter sets for English and for behaviors are one click away. Then upload or paste your roster.
2. **Rate students:** go student by student, or assignment by assignment like a gradebook column. Enter scores, click rating buttons, flag late or missing work, and add a short note.
3. **Export:** copy every student's data, with ready-made instructions for the AI, or download a CSV with one row per student.

## Your students' data stays on your computer

There's no account, no server and no database. Everything you enter stays in your own browser.

- Before closing the tab, click **Save progress** and download a save file (or copy the save code).
- To pick up later, on any computer, open **Save progress** and load that file or code.
- Keep save files somewhere private, such as your school drive, because they contain student names and ratings.

To share your setup without any student information, use **Save progress → Setup only**.

## For developers

The whole app is one file, `index.html`, with no build step and no dependencies apart from Google Fonts. To run it locally, open `index.html` in a browser. To host your own copy, fork this repository and turn on GitHub Pages (Settings → Pages → Deploy from branch → `main`, `/ (root)`).
