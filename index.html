Before you start: save your work yourself

This tool doesn't store your data online. There's no account and no server, so nobody else can see your students' information, and nobody can recover it for you either.

Before you close this tab, click Save progress and download a save file or copy your save code. Next time, open Save progress and load that file or code to pick up where you left off.

This browser keeps a temporary copy as you work, but clearing browser data or switching computers erases it. Don't rely on it.
